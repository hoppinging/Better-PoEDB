# Better-PoEDB

在 poedb.tw 和 poe2db.tw 的繁体页面上，把对应英文站的原文附在中文旁边，方便复制技能名、物品名和词缀。英文来自同路径的 `/us/` 页面，不是机器翻译。

支持的地址：

- `https://poedb.tw/tw/...`
- `https://poe2db.tw/tw/...`

目前简体、英文和其他语言页面不会改动。

## 安装

1. 打开 Edge 的 `edge://extensions`，或 Chrome 的 `chrome://extensions`。
2. 打开「开发人员模式」。
3. 选择「加载解压缩的扩展」，指向本目录。
4. 改完代码后，在扩展页点「重新加载」，并刷新已经打开的网页。

## 普通页面

扩展读取英文页，按两边相同的页面结构逐段对齐。

- 英文跟在中文后面或下一行，保留原来的布局。
- 每段英文末尾有「复制」。按钮紧挨文字。
- 导航栏、纯数字，以及本来就是英文的文字不会再附一遍。
- 两边结构对不上的行留空，不会把下一条词缀贴错。
- 不会对悬停提示框进行修改。

## 变动词缀的roll值会被替换为 #

只把方便贴到市集的词缀换成 `#`。例如 `(300—400)% increased Physical Damage` 会变成 `#% increased Physical Damage`。没有数字的句子保持原样。

会替换的位置：

- 暗金、稀有、魔法和普通物品弹窗里的词缀
- 带物品链接的物品列表
- 不在表格里的词缀标题

不会替换的位置：技能宝石弹窗、词缀等级表、词缀计算器里的等级行，以及扩展自己加上的注释。这些地方仍显示原来的数字。

## 装备词缀页

词缀列表读取 `/us/` 页面相同词缀文字。

打开词缀 T 阶表时，每一行下方只给出这一阶自己的下界均值和上界均值。

- 下界均值：区间下限的平均值
- 上界均值：区间上限的平均值

例如 `附加 (19—27) 至 (30—42) 火焰伤害` 会得到 `24.5` 和 `34.5`，也就是 `(19+30)/2` 和 `(27+42)/2`，需要注意的是，复制下界均值有时候并不能屏蔽低一阶的词缀，若想要这么做需要复制低一阶词缀的上界均值再手动+1

复合词缀按行拆开，各自复制。

## 开关

- 右下角可以隐藏或重新显示本页英文。
- 开关快捷键： `Alt+Shift+E`。
- 扩展弹窗里的「显示英文」会记住这个选择。
